# Recall v4.8

- Free Recall scoring removed.
- Grammar / naturalness scoring removed from Recall.
- No grammar model is loaded as part of the Recall flow.
- Pass condition: >=80% manually curated target chunks in a single attempt.
- Targets are hidden during recording.
- Missing targets appear only after an unsuccessful attempt.
- Starting another attempt hides them again.
- Submit remains disabled until the Recall gate has been passed.
